Sequence a minimal teaching path from what the student already knows to the
correction of their misconception.

3-5 steps. Each step is one idea. The sequence must END on the misconception being
directly confronted -- not on a general summary.

- `steps`: `order` starting at 1, the `concept`, and an `objective` phrased as what
  the student will be able to do or see.
- `target_misconception`: restate the buggy rule being corrected, as a rewrite.

Shorter is better. A 3-step path that lands is worth more than a 5-step path that
covers more ground.

Return only JSON matching the schema.
